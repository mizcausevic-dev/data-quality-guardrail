# Security Policy

## Supported Use

This repository is a portfolio project that demonstrates operational data-quality validation patterns. It should not be treated as a drop-in production control without review, hardening, and environment-specific security work.

## Reporting a Vulnerability

If you discover a vulnerability in this repository, please report it privately through GitHub security reporting or by contacting the maintainer directly through the channels listed on [kineticgain.com](https://kineticgain.com/).

Please include:

- affected file or component
- reproduction steps
- expected impact
- suggested remediation if available
